# 声屿 · Soundloom

适合手机使用的个人环境音调配工具。用自然声音和日常场景声音，调配自己的专注、放松与阅读空间。

## 功能

- 8 类声音、16 种变化：雨声、风声、鸟鸣、蝉鸣、溪流、地铁站、翻书声、键盘声。
- 独立音量滑块、实时混音与总音量调节。
- 自然和生活声音可单独使用，也可自由组合。
- 定时关闭及专注、睡眠、阅读预设。
- 在「我的声屿」保存、载入和删除多套偏好。
- 导出 30 秒双声道 WAV 混合音频。

## 直接使用

https://hyt512.github.io/soundloom/

点击「聆听我的声音」开始播放。浏览器需要用户点击后才能播放音频。

## 本地运行

无需安装依赖或构建。下载项目后，在目录中运行：

```sh
python3 -m http.server 8000
```

打开 http://localhost:8000 。也可部署到任何支持静态 HTML 的托管平台。

## 说明

声音通过 Web Audio API 程序合成，为环境音模拟，并非实地录音。偏好通过 localStorage 保存在当前浏览器，不含账号、服务器数据库或跨设备同步。清除浏览器数据会移除保存的偏好。

音频完全在浏览器中生成和导出。字体使用 Google Fonts，无法访问时自动回退到系统字体。

## 文件

- `index.html`：页面与交互控件
- `style.css`：手机与桌面响应式布局
- `app.js`：声音合成、混音、预设保存与 WAV 导出
