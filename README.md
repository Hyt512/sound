# 声屿 · Soundloom

适合手机使用的个人环境音调配工具。用自然声音和日常场景声音，调配自己的专注、放松与阅读空间。

## 功能

- 8 类声音、16 种变化：雨声、风声、鸟鸣、蝉鸣、溪流、地铁站、翻书声、键盘声。
- 独立音量滑块、实时混音与总音量调节。
- 自然和生活声音可单独使用，也可自由组合。
- 定时关闭及专注、睡眠、阅读预设。
- 与「自然之声」「生活回响」并列的「轻音乐」「人声」分类；人声下有「说话声」「唱歌」，目前均待添加音频。
- 在「我的声屿」保存、载入和删除多套偏好。
- 导出 30 秒双声道 WAV 混合音频。
- 自动保存最近 100 条调配记录（停止调节 1.2 秒后记录），记录声音、类型、独立音量、总音量和时间，可一键重新载入。
- 在「我的声屿」查看累计聆听时长、播放次数、近期记录数、已保存偏好数和近期常用声音。
- 可清空调配记录与统计，已保存偏好不受影响。

## 直接使用

https://hyt512.github.io/sound/

点击「聆听我的声音」开始播放。浏览器需要用户点击后才能播放音频。

## 本地运行

无需安装依赖或构建。下载项目后，在目录中运行：

```sh
python3 -m http.server 8000
```

打开 http://localhost:8000 。也可部署到任何支持静态 HTML 的托管平台。

## 说明

「绵绵小雨」使用用户提供的雨声音轨，其余声音通过 Web Audio API 程序合成。小雨源文件实际为约 18.9 秒的含视频媒体（上传文件名为「雨声.mp3」），已提取完整音轨并对首尾做 1 秒等功率交叠，生成约 17.9 秒的无压缩 PCM WAV 循环。浏览器通过 AudioBufferSourceNode.loop 持续播放，不存在 MP3 编码填充造成的循环间隙；实时混音与导出使用同一录音。页面暂停、定时结束或浏览器/操作系统中断时会停止播放。偏好通过 localStorage 保存在当前浏览器，不含账号、服务器数据库或跨设备同步。调配记录与统计同样只保存在当前浏览器。清除浏览器数据会移除这些记录和保存的偏好。累计时长仅统计播放中且总音量与至少一种声音音量大于零的时间；每次开始或恢复播放计为一次播放。记录与旧版保存偏好使用不同的存储键，更新后原有偏好仍保留。

音频完全在浏览器中生成和导出。字体使用 Google Fonts，无法访问时自动回退到系统字体。

## 文件

- `index.html`：页面与交互控件
- `style.css`：手机与桌面响应式布局
- `app.js`：声音合成、混音、预设保存与 WAV 导出
- `activity.js`：自动调配历史与本机聆听统计
- `recordings.js`：小雨录音加载、解码和缓存
- `assets/audio/light-rain-loop.wav`：处理循环接缝后的小雨音轨
